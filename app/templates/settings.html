本地规则模式说明

未配置 API Key、未启用 LLM 或调用失败时，系统会自动降级为确定性本地规则， 整套功能仍可完整跑通（模块聚类、文件基线档案、代码块级解析、变更时间线、职责演进主线、当前态文档修订）。

区别在于：本地规则不会对代码做语义归纳，一句话职责与文档说明基于文件名、目录、可识别的函数/类清单生成； 改动动机严格取自提交说明，信息不足时明确写「原因未知（证据不足）」，绝不脑补。

配置可用 LLM 后，重新执行「初始化扫描」即可获得更高质量的归纳结果。

四条设计原则

归纳跨提交串成职责演进主线，不复述 diff
证据动机只取自提交说明/PR；不足即标注原因未知
过滤跳过格式化/锁文件/注释，控制 Token 成本
保鲜每次同步增量修订当前态文档，避免过期
